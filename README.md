# Python Projects Collection

A set of small Python projects I've built to practice different parts of the language and ecosystem: scripting, GUIs, databases, email, and a bit of AI tooling.

## Projects

- **[AI Agent](./AI%20Agent)** — A LangChain research agent (Claude + OpenAI) that searches the web, pulls from Wikipedia, and saves structured research output.
- **[Bank App](./Bank_app)** — A command-line banking app backed by SQLite, with hashed passwords and account balances.
- **[Background Remover](./Bg_remove)** — Removes an image's background and places the subject on a clean white background.
- **[NATO Phonetic Alphabet](./List_comprehension_Nato%20Alphabet)** — Converts text into the NATO phonetic alphabet using list comprehension and a CSV lookup table.
- **[QR Code Generator](./Qrcode)** — Generates QR codes from text or URLs.
- **[Reading CSV Data](./Reading_csv_data)** — Examples of reading and working with CSV files in Python.
- **[SMTP Mail Sender](./SMTP_Mail_Sender)** — Sends emails programmatically over SMTP.
- **[Tkinter Projects](./Tkinter)** — Small desktop GUI apps built with Tkinter.
- **[Password Manager](./password-manager)** — A password manager with a UI, a built-in password generator, and clipboard support.
- **[Password Generator](./password_generator.py)** — A standalone random password generator script.
- **[Pomodoro Timer](./pomodoro-start)** — A Pomodoro-technique timer app.
- **[Python Quiz](./python_quiz)** — A command-line quiz script.
- **[Quiz Game](./quiz-game-start)** — A GUI quiz game.

Each project lives in its own folder and runs independently. Several include their own README with setup details.

## Requirements

Dependencies vary by project — check the project's own folder for a `requirements.txt` or README where one exists. Python 3.10 or newer is recommended across the board.
